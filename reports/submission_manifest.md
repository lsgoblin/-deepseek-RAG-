# 最终提交清单

本文件用于最终课程提交前核对材料，避免遗漏。

## 1. 建议提交的核心文件

- `src/`
- `requirements.txt`
- `README.md`
- `.env.example`
- `reports/final_experiment_report.md`
- `ai_deliverables/step-16-对比实验结果.md`
- `data/final/jimeng_prompt_knowledge_base.md`

## 2. 建议提交的辅助材料

- `outputs/screenshots/step-16-home-default.png`
- `outputs/screenshots/step-16-demo-character.png`
- `outputs/screenshots/step-16-demo-poster.png`
- `ai_deliverables/step-16-实验测试样例.md`

## 3. 如果老师要求压缩包

建议压缩包中保留以下结构：

```text
deployment-model-v2/
├─ src/
├─ data/
│  └─ final/
├─ outputs/
│  └─ screenshots/
├─ reports/
├─ ai_deliverables/
├─ README.md
├─ requirements.txt
└─ .env.example
```

## 4. 不建议提交的内容

- `.env`
- `src/__pycache__/`
- 本地日志文件
- 空白缓存文件
- 仅用于本地调试的临时输出

## 5. 提交前最后检查

- 是否能按 README 重新运行
- 是否有至少 3 张实验截图
- 是否有最终实验报告
- 是否有对比实验结果
- 是否去除了真实 API Key
