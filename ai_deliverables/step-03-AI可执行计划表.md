# Step 03 AI 可执行计划表

## 目标

将当前项目拆解为可按顺序执行的实施计划，便于 AI 或开发者逐步推进，不跨步、不混步。

## 执行原则

1. 先完成骨架与配置，再进入功能实现。
2. 每一步都必须有明确输入、输出和验收标准。
3. 每完成一步，补充一份对应的 Markdown 汇报。
4. 未通过当前步骤验收，不进入下一步。
5. 优先保证 CLI 最小可运行闭环，再考虑 Web UI 和扩展功能。

## 当前阶段最合理的下一步

如果环境和 Git 已处理完，下一步应直接执行：

### S04 配置模块实现

#### 任务内容

1. 在 `src/config.py` 中定义配置项。
2. 支持从 `.env` 读取环境变量。
3. 定义默认值：
   - `DEEPSEEK_BASE_URL`
   - `EMBEDDING_MODEL`
   - `VECTOR_DB_TYPE`
   - `VECTOR_DB_DIR`
   - `TOP_K`
   - `CHUNK_SIZE`
   - `CHUNK_OVERLAP`
   - `TEMPERATURE`
4. 统一路径处理方式，使用 `pathlib`。
5. 预留后续模块可直接导入的配置入口。

#### 产出要求

- `src/config.py`
- 对应的 Step 汇报文件

#### 验收标准

- 模块可独立导入
- 能读取 `.env` 配置
- 缺省值完整
- 不硬编码 API Key
