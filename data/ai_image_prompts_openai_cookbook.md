# OpenAI Cookbook：图像生成提示词实践

来源：<https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide?utm_source=chatgpt.com>  
整理时间：2026-04-22  
用途：沉淀适合生产环境的 AI 图片提示词写法，重点覆盖结构化描述、约束表达、迭代优化和编辑场景。

## 核心结论

OpenAI Cookbook 的重点不是“神秘咒语”，而是可维护、可复用、可迭代的提示词结构。文档明确指出：最好的 prompt 不一定最花哨，而是意图清楚、约束明确、后续容易修改。

## 写提示词的关键原则

### 1. 先保证结构清晰，再追求细节丰富

可维护的 prompt 格式通常比“灵感式堆词”更稳定。适合长期使用的写法包括：

- 简洁短句
- 结构化段落
- 类 JSON 字段式描述
- 指令式模板
- 标签式模板

只要“需求、约束、保持不变的部分”写得清楚，上述格式都能工作。

### 2. 对视觉要素要具体，不要只写抽象形容词

有效提示词应尽量写清：

- 材质：木头、玻璃、金属、棉布、皮革
- 形状：圆形、细长、方正、破碎边缘
- 纹理：磨砂、粗糙、光滑、颗粒感
- 媒介：照片、水彩、油画、3D 渲染、插画

如果目标是逼真照片，应该直接写出“写实照片”或“摄影感”，再补充镜头、光线、构图和真实纹理。

### 3. 构图、视角、光线必须显式写出

Cookbook 强调，镜头语言能显著提升可控性。建议明确描述：

- 景别：特写、半身、全身、远景、俯拍
- 视角：平视、低机位、高机位、顶视图
- 光线：柔光、黄金时刻、高反差、霓虹夜景
- 布局：主体居中、左侧留白、右上角放 logo

如果画面氛围复杂，比如雨夜、低照度、霓虹、电影感场景，需要额外补充尺度、环境和色彩信息，否则模型容易只保留“情绪词”，却丢掉结构细节。

### 4. 人物类 prompt 要写动作、视线和交互

对人物场景，除了写“谁”，还要写：

- 人物比例和画面范围
- 眼神朝向
- 正在做什么
- 和物体如何接触

例如，“全身入镜、脚完整可见、看向桌上的书、双手自然扶住车把”这类信息能减少姿态、比例和动作上的错误。

### 5. 约束要写成“变什么，不变什么”

这份文档对图像编辑场景给出的建议很关键：

- 明确写出需要改动的部分
- 明确写出必须保留的部分
- 每轮迭代都重复“保留项”

常见保留项包括：

- 保持人物身份不变
- 保持几何结构不变
- 保持版式不变
- 保持品牌元素不变
- 不增加水印
- 不增加额外文字

如果只允许局部改动，最好写成“只修改 X，其余全部保持不变”。

### 6. 图片里的文字要当作硬约束处理

当画面中包含标题、标签、海报文字、UI 文案时，应：

- 把要出现的文字单独写清楚
- 明确位置、字号、颜色、字体风格
- 对品牌词、生僻词、专有名词提高精度要求

Cookbook 还建议在文字量大、信息密集、小字较多的情况下，提高输出质量等级。

### 7. 多图输入时，要给每张图编号并说明关系

如果同时输入多张参考图，不要只写“参考下面几张图”，而应写成：

- 图 1：产品照片
- 图 2：风格参考
- 图 3：背景氛围参考

然后明确这些输入之间的关系，例如：

- 把图 2 的风格应用到图 1
- 把图 1 的主体放到图 3 的场景中

### 8. 长 prompt 可以用，但迭代更重要

Cookbook 的思路不是一次性把所有要求塞满，而是：

1. 先写一个干净的基础 prompt
2. 每轮只调整一个变量
3. 漂移后重新强调关键约束

这比每次都重写一个超长 prompt 更容易调试。

## 适合沉淀到知识库的模板

### 模板一：生成新图

主题：要生成的主体是谁/是什么  
场景：主体处于什么环境  
构图：近景/远景、视角、主体位置  
风格：照片/插画/水彩/3D  
细节：材质、纹理、颜色、动作  
氛围：光线、情绪、时间段  
约束：不要什么、必须保留什么

### 模板二：编辑已有图片

只修改：需要变化的元素  
保持不变：人物身份、布局、背景、颜色体系、品牌元素  
输出要求：不要额外文字、不要水印、不要改变镜头角度
