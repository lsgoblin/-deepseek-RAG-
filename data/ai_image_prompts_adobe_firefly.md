# Adobe Firefly：如何写有效文本提示词

来源：<https://helpx.adobe.com/firefly/web/generate-images-with-text-to-image/generate-images-using-text-prompts/writing-effective-text-prompts.html?utm_source=chatgpt.com>  
整理时间：2026-04-22  
用途：沉淀“高质量提示词的组成”和“怎样把描述写得更具体”的知识点，适合进入知识库的写作规范部分。

## 核心结论

Adobe Firefly 的建议非常适合做知识库里的基础写作规则。它把有效 prompt 的重点归纳为四件事：

- 具体
- 描述充分
- 有个人风格
- 能传达情绪

## 关键写法原则

### 1. 至少让 prompt 具备完整的最小表达

Firefly 建议 prompt 至少包含三词以上，并且直接描述主体、修饰词和关键词，不要在开头写“生成”或“创建”这类无效动词。

这说明一个好的 prompt 起码要具备：

- 主题对象
- 补充特征
- 视觉关键词

### 2. 具体性优先于空泛概括

相比“猫的图片”这种过于宽泛的写法，Firefly 更鼓励把内容补充成：

- 位置
- 姿态
- 场景
- 风格
- 色彩数量
- 景深

知识库里应把这类经验归纳成一句通用规则：

模糊名词只能给出方向，具体描述才能给出结果。

### 3. 细节越充分，越容易贴近预期

Firefly 特别强调，文本能描述的东西几乎都可以补进 prompt，因此建议逐层增加：

- 颜色
- 材质
- 道具
- 环境
- 背景
- 动作

这类写法非常适合“从宽泛 prompt 逐步扩展成细节完整 prompt”的教学型知识库内容。

### 4. 风格、光线和视角能显著提升画面质量

Firefly 认为，仅写主体通常不够。更好的做法是继续补足：

- 风格：数字绘画、黏土、写实、未来主义
- 光线：暖光、红蓝补光、柔光、戏剧光
- 视角或镜头感
- 画面道具与背景关系

这说明知识库里的 prompt 模板不能只停留在“主体 + 风格”，而应鼓励补“光线 + 构图 + 背景”。

### 5. 情绪词会改变图像的感染力

Firefly 单独强调了情感表达。它认为，如果 prompt 中加入受众能感知到的情绪词，图像更容易变得有记忆点和叙事感。

常见的情绪向写法包括：

- 温柔、可爱、治愈
- 强大、鼓舞、庄严
- 孤独、荒凉、梦幻

对知识库来说，这意味着“情绪词”应作为独立字段纳入提示词模板，而不是附属修饰。

### 6. 结果不满意时，优先改写 prompt

Firefly 的建议很务实：如果结果不理想，不要只怪模型，先重写提示词。  
这和 RAG 场景也很契合，说明知识库应鼓励用户做：

- 同义替换
- 增补缺失细节
- 删除无用词
- 调整风格与情绪词

### 7. 文本提示词和后期工具应结合使用

Firefly 还提到，可以在得到初稿后继续用编辑器、Photoshop、Illustrator 等工具做人工微调。  
因此知识库里可以沉淀一个实用原则：

prompt 用来快速逼近方向，后期工具负责精修落地。

## 适合沉淀到知识库的模板

### 写实型模板

主体 + 外观特征 + 场景 + 光线 + 镜头感 + 情绪

### 插画型模板

主体 + 动作 + 风格媒介 + 色彩方案 + 背景 + 氛围

### 商品/概念图模板

主体 + 材质 + 设计语言 + 道具 + 布光 + 展示方式

## 对知识库建设的价值

这篇资料最适合成为“提示词写作基础规范”。它特别适合支撑以下知识点：

- 从简单句扩写成高质量 prompt
- 怎样把抽象创意变成可视化描述
- 情绪词、光线词、风格词该放在哪里
- 为什么 prompt 需要不断改写和迭代
