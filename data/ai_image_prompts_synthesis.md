## 一句话总结

好 prompt 的本质不是堆关键词，而是把“主体、场景、构图、风格、光线、情绪、约束、输出要求”表达清楚，并通过多轮小步迭代逐渐逼近结果。

## 通用提示词框架

建议将 AI 图片提示词拆成 8 个槽位：

1. 主体：谁/什么是画面主角
2. 场景：主角位于什么环境
3. 构图：远近景、视角、主体位置、留白
4. 风格：摄影、插画、水彩、3D、海报、像素风
5. 视觉细节：材质、纹理、颜色、道具、动作
6. 光线与氛围：晨光、霓虹、柔光、压抑、治愈、史诗感
7. 约束：不要什么、哪些部分不能变
8. 输出要求：尺寸、质量、格式、是否参考原图、是否局部编辑

## 各来源共同强调的原则

### 1. 具体比空泛更重要

不要只写：

- 一个女孩
- 一张产品图
- 一只猫

更好的写法是补充：

- 外观特征
- 姿态动作
- 场景位置
- 风格媒介
- 光线和色彩

### 2. 优先描述你想要看到什么

Midjourney 和 OpenAI 都强调，应先正向写出目标画面。  
反向约束可以写，但不能代替主体描述。

### 3. 构图和镜头语言决定“像不像你想要的图”

很多失败 prompt 不是主体写错，而是没写：

- 特写还是远景
- 平视还是俯视
- 主体在中央还是侧边
- 是海报构图还是抓拍构图

### 4. 光线、风格、情绪是画面质感的放大器

如果只写“未来高跟鞋”，结果往往普通；  
如果写“未来主义高跟鞋，棚拍，暖色红蓝补光，浅景深，机械材质道具”，画面方向会明显清楚很多。

### 5. 约束必须可执行

高质量 prompt 不只是“想要什么”，还要写：

- 不要水印
- 不要额外文字
- 保持人物长相不变
- 保持版式不变
- 只修改局部区域

### 6. 迭代时每次只改一个关键变量

推荐流程：

1. 先生成基础版本
2. 第二轮只改构图或风格
3. 第三轮只改光线或色彩
4. 如果结果漂移，重新补写核心约束

这种方法比每轮重写一大段 prompt 更容易定位问题。

## 推荐的 Prompt 模板

### 模板一：通用生成

`主体 + 场景 + 构图 + 风格 + 视觉细节 + 光线/情绪 + 约束`

示例结构：

`一位短发女探险家站在废弃天文台中央，广角远景，电影感写实摄影，黄铜机械装置与尘埃颗粒细节，冷蓝月光从破碎穹顶洒下，神秘而克制，不要水印，不要额外文字`

### 模板二：人物一致性编辑

`基于原图，只修改 X；保持人物脸部特征、发型、服装主色、镜头角度和背景布局不变；不要新增文字和水印`

### 模板三：商品图/海报

`产品主体 + 材质特征 + 摆放方式 + 背景风格 + 光线方案 + 品牌约束 + 输出尺寸`

## 不同模型的使用侧重

### OpenAI

适合：

- 需要强约束的结构化 prompt
- 多图参考
- 带文字画面
- 局部编辑
- 生产化接口集成

### Midjourney

适合：

- 创意探索
- 风格尝试
- 用较短 prompt 快速找方向

### Adobe Firefly

适合：

- 从基础写作规范入手训练 prompt
- 通过细节补写和情绪词增强画面表达

## 可直接入库的经验规则

- 规则 1：主体、场景、风格至少写清三项
- 规则 2：对人物必须补动作、视线和画面范围
- 规则 3：对商品必须补材质、布光和展示方式
- 规则 4：对海报或 UI 必须补文字位置和版式约束
- 规则 5：需要稳定编辑时，写清“改什么”和“保留什么”
- 规则 6：先低成本试错，再高质量定稿
- 规则 7：结果不好时先改 prompt，再考虑换模型
